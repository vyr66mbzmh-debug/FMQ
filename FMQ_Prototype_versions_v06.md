# FMQ Prototype versions v06

## v06 — 14 October 2026

This release retains the complete v05 question library and navigation, with a modest reduction in question and solution text size to improve viewing on large classroom displays. The reading text is about 9% smaller in split view and 11–15% smaller in presentation and full-page views. Navigation labels and controls keep their previous size.

- All 137 Pure Core skills remain available: 3,543 questions and 8,641 worked-solution entries.
- No question or solution content changed from v05.
- The separate conversion status file records source discrepancies found during transcription.

Validation: the v05 import and content checks remain applicable because the question data is unchanged. The updated files identify themselves as v06 and use a new offline cache version. The v06 ZIP is checked for integrity after packaging.
