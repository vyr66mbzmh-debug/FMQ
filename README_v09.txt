FMQ Prototype v09

The question library is bundled locally so the app can load its questions without requesting a separate file for each skill. This fixes the blank library and “This skill could not be loaded” startup failure in installed or offline browser apps.

To run on a Mac, unzip the download, open Terminal, enter the unzipped folder, then run:

python3 -m http.server 8769

Leave Terminal open and visit http://localhost:8769 in Safari or Chrome.

Question 36 in Skill 1.28 uses the complete textbook diagram. The print buttons open the corrected v03 Polar Curves topic and Skill 1.28 PDFs; other printouts remain v02.
