FMQ Prototype v07

To run this prototype on your Mac, unzip the download, open Terminal, and enter the unzipped folder. Start a local web server with:

python3 -m http.server 8769

Leave Terminal open, then visit http://localhost:8769 in Safari or Chrome.

The Print topic and Print skill buttons open the selected topic or skill PDF. Use Print in the browser PDF viewer to print it.

The “Edexcel only” checkbox filters topics and skills to those present in the Edexcel specification. Clear it to restore the full library.

This version includes PDFs for all 137 skills and 22 topics, and preserves the v06 question and solution library.
