FMQ Prototype v06

Complete Further Maths A level Pure Core library: 137 skills, 3,543 questions, with worked solutions. This version uses slightly smaller question and solution text for viewing on classroom displays.

Open on your Mac
1. Unzip FMQ_Prototype_v06.zip.
2. Open Terminal and type cd followed by a space. Drag the unzipped fmq-prototype folder into Terminal and press Return.
3. Enter: python3 -m http.server 8766
4. Open http://localhost:8766/ in Safari or Chrome. Leave Terminal running while using FMQ.

Choose the course, book, topic and skill from the navigation. Reveal next shows the worked solution progressively. Full-page question and solution views, presentation mode and fullscreen controls are available.

The ZIP contains all mathematical content, diagrams and rendering files. It runs locally without an internet connection.
