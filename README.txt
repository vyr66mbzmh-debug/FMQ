FMQ Prototype v03

Unzip the archive and open fmq-prototype/index.html in your browser.
All content and fonts are included for offline use.

Use Question library to choose Skills 1.01-1.05.
Question full page enlarges the question and hides the solution and library.
Solution full page enlarges the solution and hides the question and library.
If the solution is hidden, Solution full page displays the full solution.
If you have started revealing steps, Solution full page retains the revealed steps.
Split view returns to the original layout. Escape also returns to Split view.
Reveal next starts and continues step-by-step revelation.

For a local browser server:
  cd ~/Downloads/fmq-prototype
  python3 -m http.server 8765
Then open http://localhost:8765
